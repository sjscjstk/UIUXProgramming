서비스 소개

실외 금연구역의 주소·면적·과태료·관리기관 등의 정보를 조회할 수 있는 서비스

전국의 실외 금연구역 위치와 기본 정보를 한눈에 조회할 수 있습니다.

지자체별 관리기관 정보를 확인하여 쾌적한 환경을 함께 만들어 가세요.

주요 기능

간편 검색 기능

금연구역을 간편하게 검색할 수 있습니다.

상세 검색 기능

시도명, 검색 결과 갯수, 시설 유형명 등의 항목을 선택하여 상세히 검색할 수 있습니다.

엑셀 저장 기능

조회한 데이터를 엑셀파일로 다운로드 할 수 있습니다.

이용 방법

  1. 약관 동의 및 시작 : 상세 검색에서 사용자 이름(선택)을 입력하고 이용 약관에 동의한 뒤 서비스를 시작합니다.
  2. 지역(시군구명) 입력 : 조회할 지역의 시군구명(예: 관악구, 가평군)을 한글 2글자 이상 입력합니다.
  3. 검색 조건 설정 : 검색 결과 표시 갯수(50개·100개·전체)와 상세 시설 유형(공공·교육·다중이용시설) 조건을 선택합니다.
  4. 결과 조회 및 기록 관리 : 금연구역 상세 정보(주소·면적·과태료 등)를 확인하고, 내 검색 정보에서 저장된 검색 기록을 상태별로 관리합니다.
