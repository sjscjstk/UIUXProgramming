# Smoke Free - 전국 금연구역 조회 서비스
- 공공데이터포털의 전국 금연구역 표준데이터 API로 시군구명을 검색해 금연구역 정보를 조회하는 웹페이지입니다.
- 이번 주에는 서비스 흐름에 맞는 내비게이션 목록(nav, ul, li) 구성, 현재 위치 표시(aria-current), 내 검색 정보 상태 필터링 및 결과 안내, 반응형 모바일 메뉴 기능을 구현하였습니다.

- GitHub 저장소: https://github.com/sjscjstk/UIUXProgramming
- 배포 페이지: https://sjscjstk.github.io/UIUXProgramming/

## 10주차 추가·수정한 기능

### 1. 서비스에 맞는 메뉴 구성 (nav, ul, li)
- 주요 메뉴를 nav > ul > li > a 목록 구조로 개편하고, 사용자가 목적지를 예상할 수 있도록 6개 메뉴로 구성
- 메뉴별 목적지
  1. 서비스 소개 (#about): 실외 금연구역 조회 서비스 개요 및 소개 이미지
  2. 주요 기능 (#features): 간편 검색, 상세 검색, 엑셀 저장 기능 탭 안내
  3. 이용 방법 (#steps): 금연구역 검색 및 결과 확인 단계별 안내
  4. 상세 검색 (#event-practice): 사용자 정보 입력 및 약관 동의 후 3단계 금연구역 상세 검색 진행
  5. 내 검색 정보 (#archive-search): 저장한 검색 조건 목록 조회, 상태별 필터링, 내용 보기(모달) 및 취소 관리
  6. 소식 받기 (#subscribe): 이메일 소식 신청 폼

### 2. 현재 위치 표시 (aria-current)
- 현재 보고 있는 영역에 해당하는 메뉴에 is-current 클래스(글자색·배경색·하단 강조선)와 aria-current="page"를 적용하고, 다른 메뉴에서는 제거
- 메뉴 클릭 이동(hashchange), 화면 스크롤(scroll), 새로고침(load), 브라우저 뒤로 가기(pageshow) 시에도 실제 화면 위치와 현재 메뉴 표시가 일치하도록 구현

### 3. 내 검색 정보 목록 필터와 결과 안내
- 필터 기준 (role="group"): 저장된 금연구역 검색 기록을 상태에 따라 3가지로 분류
  1. 전체 (data-filter="all"): 저장됨·취소됨 상태를 포함한 모든 검색 기록 표시
  2. 저장됨 (data-filter="active"): 취소되지 않은 활성 상태(cancelled: false)의 검색 기록만 표시
  3. 취소됨 (data-filter="cancelled"): 취소한 상태(cancelled: true)의 검색 기록만 표시
- 필터 선택 시 버튼의 is-active 클래스와 aria-pressed 속성(true/false), 실제 목록 내용이 함께 변경 됨
- 상단 배지와 안내 문구로 현재 표시 중인 항목 수(예: 전체 2개 중 ‘저장됨’ 1개를 표시하고 있어요.)를 실시간 안내
- 빈 결과 구분 안내
  1. 전체 기록이 없는 경우: "아직 저장한 검색 기록이 없어요." 문구와 함께 [검색 조건 만들러 가기] 버튼을 표시
  2. 선택한 필터 조건에 맞는 결과만 없는 경우: "선택한 조건에 맞는 검색 기록이 없어요. ‘취소됨’ 상태의 기록이 없습니다. 전체 n개의 기록이 있으니 다른 상태를 선택해 보세요." 문구를 표시하고 이동 버튼은 숨김

### 4. 모바일 메뉴 구현
- 화면 폭 600px 이하에서는 기본 메뉴를 숨기고 [메뉴 열기] 버튼을 통해 주요 메뉴를 펼치거나 접을 수 있음
- 버튼을 누르면 메뉴 표시 상태, 버튼 문구(메뉴 열기 ↔ 메뉴 닫기), aria-expanded 값(false ↔ true)이 함께 변경됨
- 펼쳐진 메뉴에서 항목을 선택하면 해당 위치로 이동한 뒤 메뉴가 자동으로 닫히며, Esc 키를 누르거나 화면 폭을 801px 이상으로 넓혔을 때도 메뉴 닫힘

## 이전 주 기능 유지 항목
- 상세 검색 폼 및 실시간 입력 검증: 모든 입력 요소에 label과 aria-describedby를 연결하고, 시군구명(한글 2자 이상 필수)과 사용자 이름(선택, 2~10자) 입력 시 실시간 조건 충족 문구 표시 및 오류 즉시 해제
- 조건부 입력: 상세 시설 유형 조건 포함 체크 여부에 따라 하위 시설 유형 영역 표시 및 라디오 활성화/비활성화 동기화
- 폼 제출 및 예외 처리: submit 이벤트 처리, 제출 중 버튼 비활성화, localStorage 저장·읽기 실패 예외 처리, 공공데이터 API 결과 출력 및 상세 보기 모달 제공

## 동작 확인 순서
1. 메뉴 이동 및 현재 위치 표시 확인
   - 상단 메뉴(서비스 소개 ~ 소식 받기)를 차례로 클릭해 각 영역으로 이동하는지 확인
   - 이동한 메뉴에 is-current 스타일과 aria-current="page"가 적용되는지 확인하고, 화면을 직접 스크롤하거나 새로고침·브라우저 뒤로 가기를 했을 때도 현재 위치 표시가 일치하는지 확인
2. 초기 빈 목록 안내 확인
   - 저장된 기록이 없을 때 내 검색 정보 영역에서 "아직 저장한 검색 기록이 없어요." 안내와 [검색 조건 만들러 가기] 버튼이 표시되는지 확인
3. 상세 검색 실행 및 검색 조건 저장
   - 상세 검색에서 약관 동의 체크 → [서비스 시작하기] → [동의하고 서비스 시작하기] 클릭
   - 시군구명(예: 관악구) 입력 후 [상세 검색하기]를 눌러 STEP 01(검색 정보) → STEP 02(검색 조건) → STEP 03(내용 확인)을 거쳐 [검색 결과 저장 및 확인하기] 클릭
   - 완료 화면에서 공공데이터 금연구역 검색 결과를 확인한 뒤 [내 금연구역 검색 보기]를 눌러 목록으로 이동
4. 목록 필터 및 상태별 빈 결과 안내 확인
   - 저장된 카드가 1개 있는 상태에서 취소됨 필터를 눌러 "선택한 조건에 맞는 검색 기록이 없어요." 안내가 나오고 [검색 조건 만들러 가기] 버튼이 숨겨지는지 확인
   - 전체 또는 저장됨 필터로 돌아와 카드의 [내용 보기] 모달을 확인하고, [검색 기록 취소하기]를 눌러 상태를 변경한 뒤 각 필터(전체/저장됨/취소됨) 선택 시 버튼의 aria-pressed, 표시 건수 문구, 배지 숫자, 실제 카드 목록이 함께 바뀌는지 확인
5. 모바일 메뉴 동작 확인
   - 브라우저 창 폭을 600px 이하로 줄여 [메뉴 열기] 버튼이 나타나는지 확인
   - 버튼을 눌러 메뉴가 펼쳐지고 문구가 메뉴 닫기로 바뀌는지 확인
   - 메뉴 항목을 클릭했을 때 해당 영역으로 이동하면서 메뉴가 자동으로 닫히는지 확인
