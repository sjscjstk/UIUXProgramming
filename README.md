## Smoke Free - 전국 금연구역 조회 서비스

### 사용자와 목표
- 사용자 : 비흡연자, 흡연자
- 목표 :  전국의 실외 금연구역 위치와 관련 정보를 사용자가 쉽고 직관적으로 검색할 수 있도록 제공합니다.

### 사용자의 흐름
1. 위치 검색 및 권한 승인 : 앱/웹 접속 후 현재 위치(GPS) 액세스를 허용하거나, 찾고자 하는 특정 지역(건물명, 지하철역, 주소 등)을 검색한다.
2. 금연/흡연구역 지도 확인 : 현재 위치 주변의 금연구역 범위를 지도상에서 직관적으로 확인한다.
3. 상세 정보 조회 및 엑셀 저장 : 특정 금연구역을 클릭하여 지정 근거 법령, 과태료 금액, 관리 주체, 단속 빈도 등의 상세 정보를 확인하고 필요 시 엑셀파일로 다운받을 수 있다.
4. 즐겨찾기 및 맞춤 알림 설정 : 자주 방문하는 이동 경로를 저장하고, 해당 구역 진입 시 금연구역 안내 알림을 받는다.

### 인터랙션 시나리오
1. 서비스 이용 동의 및 시작
- 행동, 이벤트 : 이용 약관 체크박스를 선택하고 서비스 시작하기 버튼을 클릭한다.
- 조건 : 위치 정보 제공 동의가 선택되었는가?
- 반응, 다음 상태 : 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다. 팝업에서 돌아가기를 누르거나 Esc를 누르면 동의를 해제하고 시작화면에 남는다. 동의하고 설정 시작하기를 누르면 제목 입력 화면을 연다.
2. 검색 위치 입력
- 행동, 이벤트 : 검색할 장소나 지역명(주소, 구역 이름 등)을 입력창에 적고 검색 버튼을 클릭한다.
- 조건 : 앞뒤 공백을 지운 검색어가 비어있는가?
- 반응, 다음상태 : 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다. 값이 입력되어 있으면 해당 위치를 기준으로 조회 단계로 이동한다.
3. 조건선택
- 행동, 이벤트 : 시도명, 관리기관 등 추가 상세 필터 조건을 선택하고 검색 조건을 확정한다.
- 조건 : 상세 검색 조건을 올바르게 선택했는가?
- 반응, 다음 상태 : 선택한 조건에 따라 필터링 항목이 활성화되어 반영된다. 조건을 모두 설정한 뒤 결과 확인 단계로 넘어간다.
4. 검색 결과 확인
- 행동, 이벤트 : 조회된 금연구역 목록(위치, 시간, 관리기관 등)을 읽고 필요한 경우 엑셀 저장 버튼을 클릭한다.
- 조건 : 검색 결과가 정상적으로 조회되었는가?
- 반응, 다음상태 : 검색 결과가 없으면 해당 안내 문구를 표시한다. 결과가 존재하면 목록을 화면에 출력하며, 다운로드 버튼을 눌러 엑셀파일로 결과를 확인할 수 있다.
5. 완료와 다시 설정
- 행동, 이벤트 : 검색 및 활용 완료 후 필요하면 다시 설정하기(또는 새로 검색하기)를 클릭한다.
- 반응, 다음 상태 : 입력했던 검색어와 선택 조건을 초기화하고 처음 검색 위치 입력 화면부터 다시 시작한다. (최초 진행한 이용 동의 등의 기본 설정 상태는 유지한다.)
