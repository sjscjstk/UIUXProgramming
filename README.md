## Smoke Free - 전국 금연구역 조회 서비스

### 사용자와 목표
- 사용자 : 비흡연자, 흡연자
- 목표 :  전국의 금연구역 위치 관련 정보를 사용자가 쉽고 직관적으로 검색할 수 있도록 제공합니다.

### 사용자의 흐름
1. 이용 동의 및 서비스 시작 : 이용약관에 동의한 뒤 서비스 시작하기를 누르고, 안내 팝업에서 동의하고 서비스를 시작한다.
2. 검색 위치 입력 : 검색할 지역명 또는 장소명(예: 관악구)을 입력한다.
3. 검색 조건 선택 : 조회 반경(3km / 5km / 10km)을 선택하고, 필요하면 상세 시설 유형(공공/청사, 교육/어린이, 다중이용시설) 조건을 포함한다.
4. 입력 내용 확인 : 검색 지역, 조회 반경, 시설 유형 조건 요약을 확인하고 검색 설정을 완료한다.
5. 다시 설정 : 필요하면 다시 설정하여 검색어와 조건을 초기화하고 처음 입력 화면부터 다시 시작한다.

### 인터랙션 시나리오
1. 서비스 이용 동의 및 시작
- 행동, 이벤트 : 이용 약관 체크박스를 선택하고 서비스 시작하기 버튼을 클릭한다.
- 조건 : 이용약관 동의가 선택되었는가?
- 반응, 다음 상태 : 동의 전에는 버튼을 누를 수 없다. 동의 후 클릭하면 사용 목적을 설명하는 안내 팝업이 열린다. 팝업에서 돌아가기를 누르거나 Esc를 누르면 동의를 해제하고 시작화면에 남는다. 동의하고 서비스 시작하기를 누르면 검색 위치 입력 화면을 연다.
2. 검색 위치 입력
- 행동, 이벤트 : 검색할 장소나 지역명(주소, 구역 이름 등)을 입력창에 적고 검색 조건 선택하기를 클릭한다.
- 조건 : 앞뒤 공백을 지운 검색어가 비어있는가?
- 반응, 다음상태 : 비어있으면 같은 화면에 오류를 표시하고 입력창에 초점을 둔다. 값이 있으면 저장하고 검색 조건 선택 단계로 이동한다.
3. 조건선택
- 행동, 이벤트 : 조회 반경 슬라이더(3km / 5km / 10km)를 조절하고, 필요하면 상세 시설 유형 조건 포함 체크박스를 선택한 뒤 검색 결과 확인 버튼을 클릭한다.
- 조건 : 상세 시설 유형 조건 포함이 체크되었는가?
- 반응, 다음 상태 : 체크하면 시설 유형 선택 목록(공공/청사시설, 교육/어린이시설, 다중이용시설)이 나타나며 기본값은 교육/어린이시설이다. 체크를 해제하면 목록이 숨겨지고 시설 유형 조건은 미포함으로 처리된다. 검색 결과 확인을 누르면 입력 내용 확인 단계로 이동하고, 이전을 누르면 검색 위치 입력 단계로 돌아간다.
4. 입력 내용 확인
- 행동, 이벤트: 검색 지역, 조회 반경, 시설 유형 조건 요약을 확인하고 검색 완료 하기 또는 수정하기 버튼을 클릭한다.
- 조건 : 입력한 내용과 선택한 조건이 요약과 일치하는가?
- 반응, 다음 상태 : 수정하기를 누르면 조건선택 단계로 돌아가 값을 다시 변경할 수 있다. 검색 완료 하기를 누르면 검색 설정 완료 화면으로 이동하며, 이 화면에서 다시 설정 하기를 선택할 수 있다.
5. 완료와 다시 설정
- 행동, 이벤트 : 설정 완료 화면에서 다시 설정 하기를 클릭한다.
- 반응, 다음 상태 : 입력했던 검색어와 선택 조건을 초기화하고 처음 검색 위치 입력 화면부터 다시 시작한다. (최초 진행한 이용 동의 등의 기본 설정 상태는 유지한다.)
