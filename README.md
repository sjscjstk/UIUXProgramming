
## 새로 추가된 기능
 - 공공데이터 포털의 전국 금연구역 표준데이터 API를 연동하여, 사용자가 입력한 지역명(시군구명)을 기반으로 실제 금연구역의 상세 정보(금연구역명, 주소, 면적, 과태료, 관리기관 등 17개 항목)를 검색하고 화면에 리스트 형태로 표출하는 기능 추가.
 - 그 외 추가된 기능에 맞춰 html에서 버튼명 등과 같은 일부 명칭 변경

## 새 기능의 인터랙션 시나리오 (검색 결과 조회)
 1. 사용자 행동: 3단계 입력 내용 확인 화면에서 입력값을 확인한 뒤 검색 완료 하기 버튼을 클릭한다.
 2. 확인할 조건: 공공데이터 API 서버와의 통신이 원활한가? 입력한 지역명(signguNm)에 해당하는 데이터가 존재하는가?
 3. 성공 반응: 데이터를 불러오는 동안 공공데이터를 불러오는 중입니다...라는 로딩 메시지를 표시한다. 통신 성공 시 로딩을 숨기고, API에서 받아온 금연구역 상세 정보 17개 항목을 표 형태의 카드 리스트로 화면에 출력한다.
 4. 다른 분기의 반응 (오류·결과 없음·취소)
  - 결과 없음, 오류: 입력한 시군구명에 해당하는 데이터가 없거나 오기입, 트래픽 초과나 서비스키 오류 등의 문제가 발생하면 공공데이터 포털에 안내된 에러메시지를 화면에 출력한다.
 5. 다음 행동: 검색 결과 및 상태 안내를 확인한 후 하단의 조건 다시 설정하기 버튼을 눌러 모든 값을 초기화하고 1단계(위치 입력) 화면으로 돌아갈 수 있다.

## 직접 시험한 테스트 기록
 1. 정상 경로 테스트: '관악구', '가평군' 등 데이터가 존재하는 시군구명을 입력하고 검색 완료 버튼을 눌렀을 때, 로딩 상태를 거쳐 17개 데이터 항목이 정상적으로 맵핑되어 리스트(Grid 레이아웃)로 출력됨을 브라우저에서 확인함. (너비 축소 시, 다크 테마 전환 시에도 레이아웃이 깨지지 않음)
 2. 다른 분기 테스트
  - 결과 없음: 존재하지않는 구를 입력하고 검색한 결과, 정상적으로 조건을 인식하고 안내 문구가 성공적으로 노출됨을 확인함.
  - 오류 테스트: 서비스키, 호출 URL 오입력 후 검색한 결과, 오류 안내 문구가 성공적으로 노출됨을 확인함.
